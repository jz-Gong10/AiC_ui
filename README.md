# CullPilot 前端

根据 `doc/ui` 的设计预览实现的 Web 工作台。工作区对应后端项目；业务数据经 `/api/v1` 从 Spring Boot 读取，前端不会向 Python 服务直接请求。

## 本地启动

需要 Node 24、npm，以及运行在 `http://localhost:8080` 的 `AiC_server/backend-java`。

```powershell
cd AiC_ui
npm ci
npm run dev
```

浏览器打开 `http://localhost:5173`。Vite 将 `/api` 代理到本机后端。若部署环境的 API 地址不同，可设置公开的 `VITE_API_BASE_URL`；不要放入任何服务端密钥。生产检查使用 `npm run typecheck`、`npm run lint`、`npm run build`。静态产物在 `dist/`，SPA 路由需要部署端回落到 `index.html`，`/api` 仍应转发给 Java 服务。

如果只想本地预览，无须启动后端：在登录页点击“进入本地演示（无需登录）”。仅 Vite 开发模式且浏览器地址为 `localhost`、`127.0.0.1` 或 `::1` 时显示此入口。演示提供两个工作区、示意图片、相似照片分组、人工筛选及创建工作区等交互；新增素材保留在当前页面内存中，刷新后所有演示改动重置。演示分析不会调用 AI，导出不可用。正常登录依然使用真实后端；生产构建没有可用的演示入口或模拟 API。

本地演示的数据源在 `src/shared/api.ts` 注入：同一套 `Workspace`、`Gallery`、路由、样式和动画调用同一个 API 契约，开发模式按会话选择真实接口或 `src/dev/demoApi.ts`。演示接口通过 TypeScript 校验与正式接口的返回结构；修改界面时直接编辑正式组件，不维护单独的演示网页。设计目录中的静态 HTML 只作为旧版外观参考。

未登录首页在 `src/features/landing` 实现。右上角提供浅色、深色和跟随系统切换，与工作台共享外观偏好；选择在本机保存，跟随系统模式实时响应系统明暗变化，手机端显示为带名称提示的图标按钮。宽度大于 900px 且高度大于 800px 时，首屏介绍 CullPilot，向下滚动驱动 Three.js 照片从散开到逐渐叠放，保留错开的可点选边缘，展示区向左收拢，右侧登录面板渐入并随页面停留；整个页面的鼠标移动都会带动照片视角，照片有轻缓浮动。登录面板完整显示后，可点击照片边缘或缩略图，将目标照片侧向抽出、向前提起，再落到照片堆最前面，原封面顺势退回堆里。快速连续切换会接续到最后一次选择，交互期间减小浮动，向上滚动可平滑恢复散开状态。支持模拟保留、取消保留和重置；缩略图也支持方向键切换。首次选择照片后，在前移过程中播放约 950ms 的紫粉色流光边框，亮点沿已延展的边缘移动并带有柔和拖尾，从左上角沿照片边缘延展，闭合后展示预设的模拟评分、评价理由与场景分类。中途切换、离开演示或隐藏页面会取消未完成的分析；重新选中时从零开始。已完成的照片在本次首页会话内直接复用结果，重置按钮同时清除分析记录；缩略图标记已完成分析的照片。结果明确标为模拟数据，不请求真实 AI 接口。这些模拟选择与分析记录只存在首页内存中，不提交给后端。登录/注册切换保留输入，滑动标签与表单过渡一起播放。手机、矮屏和“减少动态效果”模式使用上下排列，入口可直接滚动到表单；减少动态效果模式直接切换照片，不播放抽出或流光动画，直接显示模拟分析结果。照片纹理是仓库内的五张原创 SVG 插画，Three.js 按需加载；不支持 WebGL、图形上下文丢失或 3D 模块加载失败时显示静态插画，登录注册仍可使用。场景在不可见或页面隐藏时暂停，手机绘制限制为约 30 帧，卸载时释放 GPU 资源；注册登录继续使用同一套真实认证接口。

照片布局、筛选结果与工作区切换使用 `src/shared/viewTransition.ts` 中的内容淡入：先同步提交界面，再通过 Web Animations API 对实际内容做 180–220ms 的淡入。动画期间标签、照片与其他控件保持可点击。工作区请求并行准备目标数据，切换前最多等待 140ms 预热首屏缩略图；筛选和分页同样预热目标照片。不支持动画的浏览器直接更新界面，系统开启“减少动态效果”时跳过淡入。照片叠、弹窗和侧栏的细节动效集中在 `src/styles/motion.css`。

从首页登录、注册或进入本地演示成功后，使用同一套全屏模糊遮罩进入工作台：遮罩先用 180ms 覆盖首页，再切换路由，以品牌 v2 横向 SVG 的展开收起循环提示加载；工作区列表与首屏项目、汇总、素材请求完成（包括错误结果）后，遮罩用 240ms 淡出。快速加载时至少停留 700ms，慢请求最多额外等待 5 秒，随后露出工作台本身的加载或重试入口；不会制造百分比进度。登录失败保留表单错误提示，不进入遮罩。过渡期间暂停背景交互、锁定页面滚动，结束后将键盘焦点移到工作台；退出或会话失效会清理遮罩与计时器。深浅主题和移动端均可使用，“减少动态效果”模式使用静态加载提示并跳过额外停留与淡入淡出。刷新已有登录会话沿用原有启动加载状态。

## 品牌加载动画

统一入口是 `src/shared/BrandLoader.tsx`（图标）与 `BrandLoading`（图标加可访问的状态文字）。使用 `icons/v2/svg` 中的 `cullpilot-mark-cycle.svg` 和 `cullpilot-lockup-horizontal-cycle.svg`，保持原版 2880ms 展开 / 收起循环与比例。应用副本在 `src/assets/brand`：深色版按品牌文档改为图标 `#8BAAFF`、字标 `#F3F4F6`；补充 SVG 内部的减少动态媒体查询，此时展示展开的静态标志。主题由应用偏好决定，实色主按钮使用反色版本，内联方形尺寸至少 20px。图标装饰不重复播报品牌名，加载文字继续提供状态说明。加载完成或错误后移除循环，照片读取失败显示“照片暂不可用”。

| 使用位置 | 版本 |
| --- | --- |
| 应用启动 / 会话恢复、首页模块加载、登录 / 注册 / 本地演示进入工作台的全屏遮罩 | 横向循环 |
| 首页 3D 模块等待加载、登录 / 注册按钮等待、模拟 AI 评价准备与分析中 | 方形循环 |
| 工作区列表加载、加载更多、切换工作区、新建工作区提交 | 方形循环 |
| 素材读取、照片缩略图和原图读取、相似分组与组内照片读取、筛选与分页等待、人工筛选提交 | 方形循环 |
| 上传 / 服务端校验、提交分析、分析任务等待与处理中、取消 / 重试任务 | 方形循环 |
| 保存筛选设置、解析筛选要求、保存筛选策略 | 方形循环 |
| 提交导出任务、生成导出文件、下载 ZIP | 方形循环 |

加载图标只使用循环版本，静态品牌标识保持原样；首页 AI 评价的紫粉流光边框继续表示分析进度。

## 已接入

- 注册、登录、当前用户、退出登录；访问令牌保存在当前浏览器标签会话中。
- 多工作区创建、切换、设置、删除，以及照片分页浏览。
- JPEG/PNG/WebP 批量上传，按最多 10 张且总计不超过 100 MiB 分批；展示进度、重复和失败数量。
- 启动、查询、取消、重试分析任务；在任务完成后刷新素材与汇总。
- 人工保留、待确认和舍弃；更新时提交服务端返回的 `version`，冲突后重新读取。
- 单图、双图、总览布局，后端缩略图与原图鉴权读取，导出任务与 ZIP 下载。
- 25 种主题色、15 种组件配方、3 种照片布局、深浅色；外观保存在本机浏览器。平台相关的偏好与下载能力经 `PlatformAdapter`，便于后续接 Electron。

## 当前接口边界

Apifox 的 **CullPilot** 项目（ID `8884039`）含 25 个接口，前端请求字段以该项目与仓库 `AiC_server` 源码核对。Apifox 记录了 `GET /projects/{projectId}/groups` 和 `GET /groups/{groupId}/assets`：前端已经具备读取、按 `groupType` 分类、照片叠与展开的组件；当前 Java 源码没有这两个 Controller，分析器的分组、质量和排序也是扩展点。因此现有后端运行时通常显示“暂无分组结果”，不会伪造相似度、质量分或推荐。

自然语言解析与重排也没有可调用的 Java 接口。对话区明确提示未接入，输入只在当前页面会话内按工作区保存，不会更改推荐或人工决定。结构化筛选设置会真实保存，但当前后端尚不能据此重排。组内展开支持 Apifox 的分页契约，当前一次展示最多 100 张，并明确提示尚有更多成员。

账号与项目数据属于实际后端。与 [静态外观预览](../doc/ui/cullpilot-design-preview.html) 不同，此工程不会自动加载示例照片。

## 目录

- `src/app`：路由、鉴权、工作区和任务界面。
- `src/shared`：API、DTO、错误处理与鉴权图片读取。
- `src/features/review`：照片网格、照片叠、人工复核、单图和双图布局。
- `src/features/landing`：未登录首页、滚动展示、3D 照片与认证表单。
- `src/appearance`：外观配置与本地保存。
- `src/platform`：浏览器平台实现和 Electron 可替换接口。

本机端到端检查使用 `temp/` 下的隔离 SQLite 数据库和浏览器配置，不写入正式工作区。
